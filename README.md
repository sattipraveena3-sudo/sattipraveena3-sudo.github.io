# Praveena Satti

AI/ML researcher and engineer focused on **reliable retrieval-augmented language systems**.

## Frozen research identity

> I study reliability in retrieval-augmented language systems: how changes in retrieved evidence cause answer reversals, and how evidence-aware verification and abstention can prevent harmful transitions.

## Flagship research program

**From Measurement to Mitigation of Evidence-Induced Answer Reversals in RAG**

**Research question:** When retrieved evidence is expanded along a fixed ranking, which answer changes are harmful, why do they persist or recover, and can a change-triggered evidence-stability gate reduce correct-to-incorrect transitions without suppressing incorrect-to-correct repairs?
